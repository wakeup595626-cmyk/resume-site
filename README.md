## 🎨 网站特性与设计

- **深空黑曜石玻璃拟态（Obsidian Dark Glassmorphism）**：科技暗色调搭配电气青与电压翠绿微发光，沉稳硬核。
- **动态电网与电路粒子交互画布（Electric Circuit Canvas）**：原生 HTML5 Canvas 渲染微电流节点吸附交互。
- **Bento Grid（便当盒网格布局）**：直观展示国赛大奖、知识产权与硬核量化数据。
- **真实工程凭证内嵌**：手写签名、挑战杯国奖证书实拍、洞口县供电公司试验场、雪峰山实测及排烟枪样机。
- **多维度项目全景弹窗**：点击卡片查看配电网自愈算法与硬件防误触发判据。
- **一键切换标准A4简历（Printable Resume）**：支持一键调出打印机保存为高清 PDF。

## 🚀 本地运行

该网站为零依赖静态单页架构，直接打开 `index.html` 或通过任何静态服务器启动：

```bash
# Python 启动
python -m http.server 8080

# 或 Node.js
npx serve
```
